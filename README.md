# AutoFish

Простой и универсальный бот для авторыбалки, работающий через анализ экрана (OpenCV).

## Предыстория
Этот бот был написан чисто по фану, когда мы с другом играли в Roblox в режиме **Refinery Caves 2**. Мы поняли, что рыбалка там это самое профитное и стабильное АФК-занятие, но сидеть и кликать руками было тупо лень. Так и появилась эта программа.

## Суть
Бот смотрит на экран, находит "Сейф-зону" (цветную полоску) и старается удерживать в ней белый маркер, имитируя нажатия мыши. В настройках можно задать свои цвета, задержки, зоны кликов для авто-заброса и т.д.

## Использование
Вы можете юзать бота как есть, либо полностью переделывать код под свои нужды — он довольно гибкий и при правильной настройке цветов/зон подойдет для многих других игр с похожей механикой рыбалки. 

**Важно:** Гарантировать какие-либо обновления или поддержку я не могу. Прога делалась для себя под конкретный случай, поэтому отдаю "как есть" (as is). Берите, пользуйтесь, ковыряйте код.

## Как запустить
Если запускаете из исходников:
1. Установите библиотеки:
   ```cmd
   pip install opencv-python numpy PyQt6 mss pydirectinput keyboard
   ```
2. Запустите скрипт:
   ```cmd
   python main.py
   ```
